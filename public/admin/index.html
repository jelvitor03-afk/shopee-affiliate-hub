Progresso da Configuração no Seu PC

0 de 5 etapas prontas

Siga os 6 passos abaixo na ordem para sair do zero e deixar seu funil Shopee + WhatsApp + Campanhas rodando no Windows.

1. Shopee Open API Pendente
2. Meta Ads (ROI) Modo Demo
3. WhatsApp (QR / Cloud) Pendente
4. X1 + Catálogo Jev Pendente
5. Grupo & Anti-Ban Ajustar
Passo 1

Ligar o Sistema e Proteger sua Senha (2 Cliques)

  • Na primeira vez em um PC novo, clique 2 vezes em INSTALAR_FACIL_WINDOWS.bat (instala Node.js, FFmpeg, voz gratuita Edge-TTS e prepara tudo sozinho).
  • No dia a dia, clique 2 vezes em INICIAR_SISTEMA.bat e deixe a janela preta minimizada (desative a suspensão de tela/hibernação do Windows enquanto o robô estiver rodando).
  • Para trocar a senha do painel, abra o arquivo .env no Bloco de Notas e mude ADMIN_PASSWORD=sua-senha-nova.
  • Importante: Para usar Campanhas ROI, Grupo de Achadinhos e X1 via QR Code (Baileys) você NÃO precisa de túnel público. Só abra o ABRIR_TUNEL_PUBLICO.bat se for usar a WhatsApp Cloud API Oficial da Meta ou links /go/.
Passo 2

Conectar sua Conta Shopee Afiliados (Obrigatório)

  • Entre em affiliate.shopee.com.br → menu Open API → copie seu AppId e Secret.
  • Clique no botão abaixo, cole o Shopee AppId e Shopee App Secret e clique em Salvar Credenciais de Campanhas.
  • Sem essas 2 chaves, o robô não consegue puxar pedidos em tempo real nem gerar links curtos com sub_id.
Passo 3

Painel de Campanhas ROI Sem Pixel (Afiliado Dash)

  • No Meta Business / Gerenciador de Negócios, crie um Usuário do Sistema (ou gere um Token com permissões ads_read e ads_management) e copie o ID da Conta de Anúncios (act_123456...).
  • Cole ambos em Conexão Meta Marketing API & Shopee na aba Campanhas (ROI) e salve.
  • Como rastrear vendas sem Pixel: Na tabela de campanhas (ou no formulário Gerar Link Shopee por Campanha), clique em Vincular na campanha desejada, cole o link do produto da Shopee e gere o link curto (ele injeta o sub_id da campanha automaticamente). Cole esse link curto como URL do Site no anúncio do Facebook/Instagram.
  • Clique em Alternar Demo/Real para sair dos dados de exemplo. Use a chave verde Status para pausar anúncios no prejuízo na hora e o botão Editar para ajustar o orçamento diário.
Passo 4

Atendimento X1 Inteligente (Voz OGG/Opus + Trava Jev)

  • Canal WhatsApp: Escolha X1 via Baileys (QR Code — Grátis / Sem API da Meta) para atender no privado usando opções numeradas (1, 2, 3), ou WhatsApp Cloud API Oficial para botões clicáveis nativos (até 20 letras).
  • Cérebro de IA: Use Google Gemini / Groq (rápido e leve para qualquer notebook) ou clique nos presets Ollama Local / LM Studio Local para rodar 100% no PC sem API externa.
  • Áudio e Voz Dela: No PC sem placa de vídeo potente, mantenha Edge-TTS Local (pt-BR-FranciscaNeural) (já funciona de graça como nota de voz real OGG/Opus). Para usar voz clonada, suba um áudio .wav limpo (15 a 30s) e ative Voicebox Local (veja INSTALAR_VOZ_LOCAL_WINDOWS.md) ou ElevenLabs. Clique sempre em Testar Voz Agora para ouvir antes. Se o motor de voz falhar em algum envio, o sistema entrega o texto automaticamente para nunca perder a venda.
  • Catálogo RAG + Jev (Zero Mentira): Cadastre cada produto anunciado (preço, link de afiliado e dúvidas como voltagem/tamanho/material). Se o cliente perguntar algo fora do catálogo, a trava Jev bloqueia chute e coloca a conversa em Aguardando Humano.
  • Assumir pelo Celular (Human Takeover): Basta responder o cliente normalmente pelo seu celular que o robô detecta sua resposta e fica em silêncio por 30 minutos naquela conversa.
Passo 5

Grupo de Achadinhos no Piloto Automático

  • Recomendado usar um chip dedicado/aquecido.
  • Na aba Grupo de Achadinhos, clique em Conectar / Gerar QR Code e escaneie no WhatsApp (Aparelhos Conectados).
  • Clique em Buscar Meus Grupos, selecione o seu grupo VIP, escolha as palavras-chave (ex.: achadinhos, cozinha, organizador), o horário permitido (8h às 22h), marque Ativar postagem automática e salve.
  • Clique em Disparar 1 Oferta Agora para testar na hora (o banco SQLite garante que o mesmo produto nunca seja repetido).
Passo 6

Blindagem Anti-Ban (Proteção do Chip)

  • Chip novo (1ª semana): clique no preset Conservador (8 envios/hora, 25/dia).
  • Chip em aquecimento (2ª–3ª semana): use Moderado (15/hora, 40/dia).
  • Chip antigo/validado: use Veterano (30/hora, 120/dia).
  • O sistema já agrupa mensagens seguidas do cliente em 1 resposta só (Debounce), bloqueia envios se o cliente digitar parar/sair (Blacklist) e aciona o freio de emergência (Circuit Breaker) se houver 3 falhas seguidas.

Perguntas Rápidas & Solução de Problemas

A tabela mostrou valores de exemplo ("Modo Demo")

Normal na primeira abertura. Assim que salvar seu Meta Ad Account ID, Meta Marketing Token e chaves da Shopee, clique em Alternar Demo/Real no topo da aba Campanhas (ROI).

O áudio de voz não tocou ou falhou no cliente

O sistema nunca deixa o lead sem resposta: se o motor TTS falhar, ele envia a resposta em texto automaticamente e registra no Log. Teste antes em Testar Voz Agora (INSTALAR_FACIL_WINDOWS.bat já instala FFmpeg + Edge-TTS).

Fechei a janela preta ou o Windows hibernou

Sem a janela preta aberta o robô pausa. Ajuste o plano de energia do Windows para Nunca suspender quando conectado na tomada e dê 2 cliques em INICIAR_SISTEMA.bat.

Apareceu alerta vermelho de Circuit Breaker

Freio acionado após 3 erros seguidos de envio ou queda de QR Code. Confira se o WhatsApp continua conectado na aba Grupo de Achadinhos e clique em Retomar Envios na aba Blindagem Anti-Ban.
